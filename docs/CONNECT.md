# 客户端怎么连（手机 / 笔记本 / 平板）

> 服务端怎么搭见 [DEPLOY-SERVER.md](DEPLOY-SERVER.md)。这里只讲**拿到地址之后**怎么用。

你需要三样东西，都在 dsh 的 **设置 → 远程访问** 面板里：

| 需要什么 | 在面板哪里 |
|---|---|
| 访问地址 | 「手机访问地址」（局域网）或「公网访问」卡片上的地址（人在外面） |
| 访问密码 | 你自己在「访问密码」里设的（忘了就在那里改，改完所有设备需重新登录） |
| 二维码 | 「扫码配对」（局域网，一次性）或「公网访问」卡片（公网入口） |

---

## 1. 手机（最常见）

1. 手机相机对准「公网访问」卡片上的二维码（或者直接把地址发到手机微信里点开）；
2. 打开后是一道登录页：**输入访问密码** → 继续；
3. 进入 dsh，界面和电脑上一样，只是排版变成手机版（侧栏收成抽屉、按钮变大、输入框贴键盘）。

**建议加一个桌面图标，用起来像 App：**

| 系统 | 操作 |
|---|---|
| iOS Safari | 底部「分享」→「添加到主屏幕」→ 添加 |
| Android Chrome | 右上「⋮」→「添加到主屏幕」/「安装应用」 |
| 鸿蒙 / 微信内置浏览器 | 建议先在系统浏览器打开，再添加到桌面（微信内置浏览器不能装 PWA） |

加入主屏后从图标打开是**全屏、无地址栏**的，回到上次的位置，跟 App 没区别。

## 2. 笔记本 / 平板

把地址存进书签即可。第一次输入密码，之后 **30 天内免登录**（浏览器清 Cookie 或换浏览器要重来）。

## 3. 临时给别人看（不想告诉密码）

面板「扫码配对」→ 生成一个**一次性**链接（默认 180 秒有效、用一次就失效）→ 发给他。
他打开就是你的 dsh，不需要密码；到期或用过之后链接自行作废。

> 对方拿到的是**你 dsh 的完整权限**（能看会话、能发指令）。只发给信得过的人，
> 用完可以在「已授权设备」里把那一台「移除」。

## 4. 登录页会看到什么

```
远程访问 · Remote access
验证这台设备
这台设备正在通过局域网/公网访问你电脑上的 DeepSeek Harness。
[ 输入密码            👁 ]
[        继续 →        ]
密码在桌面端「设置 → 远程访问」中设置。
局域网 10.150.23.97:3081 · v0.1.0
```

* 右上角月亮/太阳图标：亮色 / 暗色 / 跟随系统 三态切换，记在本机；
* 输错 5 次会锁定（60 秒起，翻倍，最长 15 分钟）——不是坏了，是防爆破；
* 页面**不加载任何外部资源**，也不发任何第三方请求。

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 地址打开是「The host is offline」 | 家里的 dsh 没开 / 没连上中转。回电脑看面板「公网访问」是否**已连接** |
| 打开是 relay 的 404 页 | 用面板上**当前显示**的地址（换过令牌就会变） |
| 输入密码一直提示错误 | 确认是在**电脑上最近设置**的那个密码；忘了就在面板里改 |
| 提示「已锁定，请在 N 秒后重试」 | 连续输错触发了锁定，等倒计时结束 |
| 页面能打开但一直转圈/空白 | 反向代理缓冲了流式响应 → 见部署文档的 `flush_interval -1` / `proxy_buffering off` |
| 用一会儿掉线，刷新又好了 | 代理 idle timeout 太短，或手机切网。dsh 会自动重连；必要时刷新 |
| 手机上对话框/表格被截断 | 请确认插件已安装并启用（界面底部会有抽屉按钮）；这是本插件修的官方排版问题 |
| 换了手机/浏览器要重新登录 | 会话与浏览器 UA 绑定，这是特性：旧 Cookie 被复制到别处也用不了 |

## 6. 快捷入口

| 想直接做什么 | 地址 |
|---|---|
| 打开面板（设置 → 远程访问） | 在任意 dsh 页面地址后加 `?panel=1` |
| 只看门户健康状态（不需要登录） | `https://你的公网地址/__t/<id>/__portal/health` |

## 7. 客户端安全须知

* 公网地址**不是**凭据：任何人拿到它也要过密码 / 一次性配对码。
* 在公共电脑上用完后，去面板「已授权设备」里把那一台「移除」，或直接改密码。
* 手机上的 dsh 和你电脑上的 dsh 是**同一个会话**：手机上下的指令，电脑上立刻能看到结果。
* 传输层：局域网直连默认是 HTTP（同网段可抓包，介意就配 TLS）；公网走 relay 时，
  浏览器↔服务器是 HTTPS，家里↔服务器是 TLS。
